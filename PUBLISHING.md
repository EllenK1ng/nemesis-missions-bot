# Publishing Plan

## Release Order

1. Create a GitHub repository named `nemesis-missions-bot`.
2. Upload only the contents of this folder: `public_release/nemesis-missions-bot`.
3. Do not upload `.env` or `data/state.json`.
4. Add a first release tag: `v0.1.0`.
5. In the release notes, say that this is an unofficial fan-made local Telegram bot for Nemesis objective dealing.

## Suggested Short Post

Title:

```text
Unofficial Nemesis Telegram objective dealer with fan missions
```

Text:

```text
Hi! I made an unofficial local Telegram bot for Nemesis objective dealing.

It creates a password-protected game, lets players join from their own Telegram accounts, deals one corporate objective and one personal objective to each player without repeats, and closes the session after everyone chooses one objective.

Current features:
- Base Nemesis and Carnomorphs pools
- Russian and English mission files
- Optional special fan objectives for the base game
- Player-count filtering for objectives tied to player numbers
- Runs locally; no paid server required

GitHub: <link>

No official card scans are included. This is a fan-made utility for groups that want more objective variety.
Feedback on wording, balance, and compatibility with expansions is welcome.
```
