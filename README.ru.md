# Nemesis Missions Bot

Неофициальный локальный Telegram-бот для раздачи скрытых целей в партиях Nemesis.

Бот позволяет хосту создать партию с паролем, игрокам подключиться со своих Telegram-аккаунтов, а затем каждому игроку выдаётся одно задание корпорации и одна личная цель без повторов. После того как все игроки выбрали одну из двух целей, бот автоматически закрывает партию для себя.

Проект фанатский и не связан с Awaken Realms. В репозитории нет сканов официальных карт или официальных изображений карточек.

## Возможности

- Команды хоста доступны только чату из `HOST_CHAT_ID`.
- Отдельное меню команд Telegram для хоста и игроков.
- Пулы миссий для базовой Nemesis и Carnomorphs.
- Опциональные special-миссии для базовой игры.
- Раздача без повторов внутри одной партии.
- Фильтр миссий по количеству игроков.
- Русские и английские файлы миссий.

## Быстрый Запуск

1. Установите Python 3.9 или новее.
2. Запустите бота один раз. Если файла `config.json` ещё нет, бот создаст его рядом с `bot.py` и остановится.
3. Откройте `config.json` и впишите токен бота, chat ID хоста и язык.

```json
{
  "TELEGRAM_BOT_TOKEN": "paste_bot_token_here",
  "HOST_CHAT_ID": "paste_host_chat_id_here",
  "BOT_LANGUAGE": "ru"
}
```

`BOT_LANGUAGE=ru` включает русские миссии, `BOT_LANGUAGE=en` - английские.

4. Запустите бота:

```powershell
python bot.py
```

На Windows можно просто дважды нажать `Start Nemesis Bot.bat`.

Если вы не знаете свой `HOST_CHAT_ID`, оставьте его пустым, запустите бота и отправьте ему `/start`. Бот покажет ваш chat ID.

## Команды

Хост:

- `/newgame` - создать партию и выбрать режим.
- `/deal` - раздать миссии всем участникам.
- `/players` - показать список игроков.
- `/missions` - показать количество миссий.
- `/endgame` - досрочно закрыть активную партию.

Игроки:

- `/start` или `/help` - открыть подсказку.
- `/join` - войти в партию; пароль бот попросит отдельным сообщением.
- `/leave` - выйти до раздачи миссий.

## Файлы Миссий

Русские миссии:

- `missions/ru/normal/corporate.json`
- `missions/ru/normal/personal.json`
- `missions/ru/carnomorphs/corporate.json`
- `missions/ru/carnomorphs/personal.json`

Английские миссии:

- `missions/en/normal/corporate.json`
- `missions/en/normal/personal.json`
- `missions/en/carnomorphs/corporate.json`
- `missions/en/carnomorphs/personal.json`

Формат миссии:

```json
{
  "id": "corp_001",
  "title": "Название миссии",
  "text": "Текст миссии",
  "source": "custom"
}
```

Дополнительные поля:

- `requires_player_number` - минимальное количество игроков для миссии.
- `max_player_count` - максимальное количество игроков для миссии.
- `special` - пометка special-миссии с дополнительной логикой бота.

## Настройки И Безопасность

Настройки бота хранятся в файле `config.json`, который создаётся локально рядом с `bot.py`. В публичный репозиторий его загружать нельзя, потому что там будут токен бота и chat ID.

Настоящие `TELEGRAM_BOT_TOKEN`, `HOST_CHAT_ID`, `config.json` и `data/state.json` должны оставаться только на компьютере пользователя.

Для совместимости бот также умеет читать переменные окружения и `.env`, но основной рекомендуемый способ настройки - `config.json`.
